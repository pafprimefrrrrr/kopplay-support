# KopPlay Support

Static, English-language support site for `support.kopplay.fun`.

The site intentionally uses no forms, JavaScript, analytics, advertising, cookies, remote fonts, or third-party media. Support and private security reports use the published email address. GitHub Pages and network providers may still process ordinary technical connection logs under their own policies.

## Publication checks

- Serve the repository root with GitHub Pages.
- Keep the custom domain in `CNAME` synchronized with Hostinger DNS.
- Verify HTTPS, navigation, `mailto` links, sitemap, and the absence of private QA artifacts before every deployment.
- Do not claim marketplace availability until the Asset Store product is actually published.
