Casual Meta Campaign Builder

Author, validate, execute and migrate structured casual meta-progression campaigns with transactional resources, durable world states and bounded local persistence.

Availability: this page is being prepared for the product's Unity Asset Store release. A marketplace link will be added only after publication.

What the toolkit includes

Structured authoring

Campaign, area, segment, task and task-step authoring with stable identifiers, validation and diagnostics.

Safe progression

Transactional costs, rewards, flags, unlocks, variants and persistent target states with idempotent receipts.

Migration and recovery

Explicit schema/content migrations and bounded local JSON persistence with checksum, journal and backup recovery.

What the buyer supplies

The base toolkit does not supply a core gameplay loop, game UI, art/content, backend, cloud save, authentication, IAP, live-operations service, analytics vendor or vendor-specific adapter. These remain consumer-owned integrations through documented ports.
