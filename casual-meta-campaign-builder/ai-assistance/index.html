AI assistance disclosure

AI-assisted development was used for source code, documentation and procedural samples. Shipped content was reviewed and validated; no AI service or runtime dependency is required.

Scope

Assistance included planning, drafting, implementation support, review support, terminology checks and test/evidence reconciliation. The package contains original source, Markdown documentation, Unity metadata and procedurally constructed samples; it does not redistribute generated bitmap art, audio, video, models or third-party runtime binaries.

Controls

AI assistance is not treated as proof. Compatibility, API stability, persistence behavior and device claims require separate machine-checkable tests and dated evidence. Human review of the final listing, provenance and licensing remains required before marketplace submission.

Runtime

The package runs locally and does not call an AI model, external AI API or generative service. Buyers do not need an AI account or subscription.
