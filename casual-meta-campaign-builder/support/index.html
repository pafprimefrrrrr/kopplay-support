Product support

For reproducible package defects, documentation questions and installation issues on qualified versions.

Before contacting support

  1. Confirm the exact package and Unity versions.
  2. Run Campaign validation and record the stable diagnostic codes.
  3. Check whether the issue reproduces in a fresh project or imported sample.
  4. Remove credentials, private project content, raw save payloads and personal paths.

Contact and response target

Email kopplaygame@gmail.com with a subject beginning [Casual Meta]. KopPlay aims to acknowledge support reports within five business days. This is a service target, not a contractual resolution deadline.

Support boundary

Support covers installation/removal, documented package behavior, built-in authoring and runtime workflows, diagnostics and shipped samples on qualified versions. It does not include modifying private projects, building custom gameplay/UI/backend integrations, recovering overwritten data, or guaranteeing performance on undisclosed hardware and content.

Do not send a complete private project as the first diagnostic step. Support will never request passwords, API keys, payment details or unredacted player data.
